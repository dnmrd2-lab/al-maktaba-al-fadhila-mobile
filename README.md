# تطبيق فضيلة الشيخ عبدالله بن إبراهيم بن عثمان القرعاوي — إمام الجامع الكبير (جامع خادم الحرمين الشريفين ببريدة)

تطبيق عربي بـ **Expo SDK 54 / React Native**. واجهات التطبيق وتكامل Supabase جاهزان في الكود، لكن ربط نسخة Expo بقاعدة الكتب الصحيحة ما زال خطوة إعداد لازمة قبل اعتبارها جاهزة للإطلاق.

## الوظائف المنفذة

- الرئيسية، تصفح التصنيفات، البحث العربي، تفاصيل الكتاب، المفضلة، والإعدادات.
- جلسة Supabase Auth لموظفي المكتبة، مع صلاحيات إدارة ونشر مرتبطة بالأدوار وسياسات RLS.
- لوحة إدارة هاتفية لإضافة كتاب كمسودة واختيار PDF ورفعه بحساب المستخدم.
- حفظ المفضلة وموضع القراءة والعلامات المرجعية على الجهاز.
- التصفح والقراءة متاحان دون تسجيل حساب؛ كل كتاب يحتفظ بموضعه وعلاماته على جهاز القارئ، ويمكن استكمال عدة كتب كلٌّ من موضعه. لا تتم مزامنة التقدم بين أجهزة الشخص نفسه.
- حالة خطأ مفهومة ومهلة اتصال؛ لا ينبغي أن يبقى تحميل المكتبة معلقًا إلى ما لا نهاية إذا غاب المخطط أو تعذر الاتصال.
- فتح ملفات PDF عبر عارض النظام/المتصفح برابط موقّع قصير الأجل؛ لا يوجد عارض PDF أصلي مضمّن بعد.

## إعداد قاعدة Supabase في EAS

يحتاج التطبيق إلى متغيري اتصال عامين في بيئات البناء `development` و`preview` و`production`:

```text
EXPO_PUBLIC_SUPABASE_URL
EXPO_PUBLIC_SUPABASE_PUBLISHABLE_KEY أو EXPO_PUBLIC_SUPABASE_ANON_KEY
```

يقبل التطبيق الاسمين للمفتاح العام؛ إعداد EAS الحالي يستخدم `EXPO_PUBLIC_SUPABASE_ANON_KEY`. يجب أن يشير الرابط والمفتاح إلى مشروع Supabase نفسه. المشروع المستخدم حاليًا للمكتبة هو `shevwsbzkgdguucpbkcl`.

استخدم مفتاح `publishable`/`anon` العام فقط. لا تضع `service_role` أو أي مفتاح إداري داخل التطبيق أو مستودع GitHub.

## التشغيل والتجربة

```bash
pnpm install
pnpm dev
```

يعرض أمر التطوير معاينة Expo على الويب. لاختبار Android/iOS، امسح QR من Expo Go؛ بعض الميزات native قد تحتاج development build.

## بناء ملفات متجر Android/iOS

المشروع مهيأ بـ`ios.bundleIdentifier` و`android.package`. لم يُنتج APK/AAB أو IPA في هذه المهمة. يلزم إعداد EAS أو Android Studio/Xcode وبيانات توقيع المتاجر واختبار أجهزة فعلية.

## متطلبات ما قبل الإطلاق

1. توحيد أسرار Expo وWebDev على مشروع `nifsim…`، ثم اختبار قراءة الكتب والتصنيفات من نسخة الهاتف نفسها.
2. تطبيق `supabase/migrations/20261016000000_public_read_published_library_files.sql` على مشروع المكتبة لتمكين القراءة العامة لملفات PDF المنشورة فقط؛ يبقى الوصول إلى ملفات المسودات للمسؤولين.
3. رفع ملفات PDF معتمدة والتحقق من الحقوق والبيانات الوصفية؛ لم يتضمن أرشيف الويب الأصلي ملفات PDF فعلية.
4. اختبار تسجيل الدخول والرفع والتقدم في القراءة على Android وiOS.
5. إعداد ملفات التوقيع وEAS profiles قبل إصدار المتاجر.
